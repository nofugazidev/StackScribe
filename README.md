# StackScribe
🚀 DevLog – A lightweight, developer-centric blog platform built with ⚛️ React + 🔥 Firebase. Easily ✍️ create, 🛠️ edit, and 🗑️ delete posts with ⚡ real-time updates, 📄 pagination, and 🔒 secure Firestore storage. Perfect for 💻 coders to share 📚 insights, 🧑‍💻 project logs, and 📝 tutorials in a fast, minimal, and tech-friendly space.
